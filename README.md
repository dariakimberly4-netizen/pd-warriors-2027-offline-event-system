# PD Warriors 2027 Offline Event System

A separate offline-first event system for Parkinson’s Disease Warriors Philippines — Get Together 2027.

## Included
- Orbit-first event portal
- Attendance
- Walk-in registration
- Snack and lunch claims
- Participant-only raffle eligibility
- One QR event pass
- QR camera and screenshot scanning
- Roster import
- Offline PWD / Senior Citizen ID collection
- Offline authorization letter collection
- Document verification status
- JSON backup and CSV report
- Service-worker offline cache
- Responsive mobile and desktop layout

Open the site once while online and use **Reports & Setup → Prepare / refresh offline files** before event day.
